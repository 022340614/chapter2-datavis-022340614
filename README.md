# 第二章 - 基础图表数据可视化平台

基于第二章内容构建的交互式数据可视化平台，完整展示10种基础图表类型。

## 🚀 功能特性

- **10种图表类型**: 完整覆盖第二章所有图表类型
- **交互式体验**: 支持图表缩放、悬停提示、数据筛选
- **响应式设计**: 完美适配桌面端和移动端
- **现代化UI**: 渐变背景、卡片式布局、动画效果
- **实时渲染**: 使用Plotly.js实现高性能图表渲染

## 📊 包含图表类型

### 1. 折线图 (Line Chart)
- **未来15天气温变化趋势**: 最高气温和最低气温对比分析

### 2. 柱形图 (Bar Chart)  
- **阿里巴巴GMV数据**: 2013-2019财年淘宝天猫平台交易额

### 3. 条形图 (Horizontal Bar Chart)
- **网购替代率分析**: 18种商品类别的网购替代率排名

### 4. 堆积面积图 (Stacked Area Chart)
- **物流费用统计**: 三家物流公司全年费用堆积分析

### 5. 直方图 (Histogram)
- **随机数据分布**: 10000个随机数的频数分布直方图

### 6. 饼图 (Pie Chart)
- **支付宝消费分布**: 8种消费类别的占比分析

### 7. 散点图 (Scatter Plot)
- **汽车速度与制动距离**: 速度与制动距离的散点关系

### 8. 箱形图 (Box Plot)
- **全国发电量统计**: 2017-2018年发电量箱形图对比

### 9. 雷达图 (Radar Chart)
- **霍兰德职业兴趣测试**: 六种职业兴趣类型雷达分析

### 10. 误差棒图 (Error Bar Chart)
- **树种生物量误差分析**: 四个树种生物量的误差范围

## 🛠️ 技术栈

- **Plotly.js** - 专业的交互式图表库
- **HTML5/CSS3** - 现代Web标准
- **JavaScript ES6+** - 现代化编程语言
- **响应式网格布局** - CSS Grid + Flexbox

## 🎨 设计特色

- **渐变背景**: 紫色到蓝色的渐变色系
- **卡片式设计**: 圆角阴影的现代化卡片
- **悬停效果**: 鼠标悬停时的动画反馈
- **图标标识**: 每个图表类型都有对应的emoji图标
- **色彩搭配**: 协调的色彩方案，确保数据可读性

## 📱 响应式特性

- **桌面端**: 多列网格布局，最大化利用屏幕空间
- **平板端**: 自适应调整列数和图表尺寸
- **移动端**: 单列布局，优化触摸交互体验

## 🔧 使用说明

1. 直接在浏览器中打开 `index.html` 文件
2. 支持所有现代浏览器（Chrome、Firefox、Safari、Edge）
3. 无需安装任何依赖，开箱即用

## 🌐 部署方式

### GitHub Pages部署
1. 将项目推送到GitHub仓库
2. 启用GitHub Pages功能
3. 访问地址: `https://[用户名].github.io/chapter2-datavis-022340614/`

### 本地部署
1. 下载项目文件
2. 使用任何HTTP服务器（如Python SimpleHTTPServer、Live Server等）
3. 在浏览器中访问 `http://localhost:8000`
