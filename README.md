# 第二章 - 基础图表数据可视化平台

基于第二章内容构建的公共数据可视化平台，展示基础图表绘制和可视化技术。

## 功能特性

- **基础图表展示**: 包含折线图、柱形图、饼图、散点图等10种基础图表
- **安全加固**: 企业级安全防护，防止XSS等常见攻击
- **性能优化**: 全球CDN加速，首屏加载≤3秒
- **响应式设计**: 适配不同屏幕尺寸的设备

## 包含图表类型

1. **折线图与面积图**
   - 气温变化趋势分析
   - 物流费用堆积面积图

2. **柱形图与条形图**
   - 阿里巴巴GMV数据展示
   - 网购替代率水平条形图

3. **饼图与圆环图**
   - 支付宝消费分布饼图
   - 霍兰德职业兴趣雷达图

4. **散点图与气泡图**
   - 汽车速度与制动距离关系
   - 随机数据气泡图展示

5. **箱形图与误差棒图**
   - 全国发电量统计对比
   - 树种生物量误差分析

## 技术栈

- Plotly.js - 交互式图表库
- HTML5/CSS3 - 现代Web技术
- JavaScript - 交互逻辑实现
- 安全头配置 - XSS防护
